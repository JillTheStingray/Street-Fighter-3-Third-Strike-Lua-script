# Street-Fighter-3-Third-Strike-Lua-script
This is a lua script for SFIII 

This was designed to work in Fightcade, as Enable Cheats does not work there.
This only works offline; if you are able to make it function in online matches, I am not liable for any sanctions or bans.

## Controls
- `M` show / hide the menu
- `Q` / `E` switch tabs (P1, P2, System, Parry, Universal)
- `Up` / `Down` select a cheat
- `Left` / `Right` toggle a cheat or change its option (every option list starts at "Disabled")

## Address sources
- FBNeo official cheat file: [finalburnneo/FBNeo-cheats](https://github.com/finalburnneo/FBNeo-cheats) (`cheats/sfiii3n.ini`)
